# Robot Executability Checks

Replay and kinematic evaluation tools for TacClaw-Infinity, organized by robot.

| Robot | Guide | Main workflow |
| --- | --- | --- |
| Tianji | [tianji/](tianji/) | Aik7 replay, reachability, and manipulability |
| DM-Sparky | [dm-sparky/](dm-sparky/) | Fixed-torso evaluation and 18-DoF joint solving |
| RealMan RM75-B | [realman/](realman/) | Dual-arm episode evaluation and replay rendering |

Run installation and evaluation commands from the selected robot directory. Each robot has its own environment, configuration, model assets, and tests.

See the [quick start](../README.md#code) and [source version notes](../docs/CODE_IMPORT.md). Each robot guide describes the required coordinate frame, TCP convention, and scene registration.
